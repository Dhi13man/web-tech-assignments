# web-tech-assignments

Course assignments for CS-481 Web Technologies, built with HTML, CSS, PHP, and JavaScript only (no SPA framework). Open `index.html` or `index.php` to reach the landing page under `pages/`.

## Install

A local PHP-capable server is enough for the PHP pages. Static HTML can be opened from disk.

```sh
git clone https://github.com/Dhi13man/web-tech-assignments.git
cd web-tech-assignments
php -S localhost:8080
```

Then open `http://localhost:8080/index.php` (redirects to `pages/landing/landing_page.html`).

## Use

Assignment pages live in `pages/`. `composer.json` is present for PHP tooling; the pages themselves are course exercises, not a packaged library.
